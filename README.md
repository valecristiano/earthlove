# EarthLove Backend

EarthLove è il backend di un progetto e-commerce dedicato ai prodotti sostenibili, sviluppato con **Laravel** e **MySQL**. Include un pannello amministrativo per la gestione dei contenuti e un insieme di API REST per fornire i dati al frontend sviluppato in React.

## Funzionalità

- **Autenticazione:** accesso protetto al pannello amministrativo tramite Laravel Breeze.
- **Gestione CRUD:** creazione, visualizzazione, modifica ed eliminazione di prodotti, categorie, brand e tag.
- **Gestione del database:** database MySQL con relazioni tra le diverse entità.
- **Upload immagini:** caricamento e gestione delle immagini dei prodotti.
- **Pannello amministrativo:** interfaccia per la gestione dei contenuti realizzata con Laravel Blade.
- **API REST:** endpoint per recuperare i dati dei prodotti e le informazioni correlate, utilizzati dal frontend React.

## Tecnologie utilizzate

- PHP
- Laravel
- Laravel Breeze
- MySQL
- Blade
- REST API
- Git

## Obiettivo del progetto

Realizzare il backend di un'applicazione web full-stack, integrando Laravel per la gestione dei dati e dei contenuti tramite un pannello amministrativo e React per la visualizzazione dei prodotti e delle relative informazioni.
